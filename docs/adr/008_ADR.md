# 008_ADR: Architecture du Serveur Factice d'Inférence Vocale (Mock TTS Server) et Variables d'Environnement

- **Statut :** Accepté (Accepted)
- **Auteurs :** Thomas Gauthier & Antigravity (Google DeepMind Team)
- **Date :** 2026-07-26
- **Version du Plugin :** v1.0.0

---

## 1. Contexte & Problématique

Lors du développement local et de l'exécution des suites de tests automatisées (CI/CD), le serveur d'inférence TTS de production (`audio-mlx` / Kokoro) peut ne pas être installé ou disponible sur la machine.

Un serveur de mock HTTP local est nécessaire pour simuler le comportement exact de l'API vocale sans dépendances lourdes de modèles IA, avec une configuration flexible par variables d'environnement.

---

## 2. Décisions d'Architecture

### D1. Conformité au Protocole OpenAI / Kokoro Audio API
- **Endpoint :** `POST /v1/audio/speech` sur le port configuré (`PORT`, défaut `8888`).
- **Payload :** Représentation JSON `{ "model": "mlx-kokoro", "input": "...", "voice": "Thomas" }`.
- **Réponse :** Flux binaire audio HTTP `200 OK` avec en-tête `Content-Type: audio/aiff`.

### D2. Dictionnaire des Variables d'Environnement & `.env.example`
- **`PORT`** (défaut `8888`) : Port HTTP d'écoute du serveur mock.
- **`HERDR_TTS_ENDPOINT`** (défaut `http://127.0.0.1:8888/v1/audio/speech`) : URL de l'endpoint d'inférence vocale.
- **`HERDR_TTS_VOICE`** (défaut `Thomas`) : Voix par défaut pour la synthèse vocale.
- **`HERDR_VOICE_DEBUG`** (défaut `0`) : Niveau de log étendu de débugging.
- **`CI`** (détecté automatiquement) : Active le mode binaire factice sans carte son en environnement Headless (GitHub Actions).

### D3. Double Mode de Génération Audio (Local vs CI/CD Headless)
- **Mode macOS Local (`process.platform === 'darwin'`) :** Génération du véritable son via le moteur natif macOS (`say -v <voice>`).
- **Mode CI/CD Headless (`process.env.CI = 'true'`) :** Génération instantanée d'un buffer binaire AIFF factice valide en mémoire.

### D4. Norme de Logging Console (Wording en Anglais)
- Tous les messages de démarrage et d'inférence du serveur de mock sont horodatés au format ISO et rédigés en **anglais** (`[HH:MM:SS] 🎙️ [MOCK-TTS] ...`).
