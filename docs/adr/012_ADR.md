# 012_ADR: Correctif de la CI GitHub Actions & Point d'Entrée Minimal

- **Statut :** Accepté (Accepted)
- **Auteurs :** Thomas Gauthier & Antigravity (Google DeepMind Team)
- **Date :** 2026-07-28
- **Version du Plugin :** v1.0.0-alpha.1

---

## 1. Contexte & Problématique

La pipeline GitHub Actions CI sur la branche `master` échouait en raison de l'absence du point d'entrée JS dans `src/index.js` et des tests unitaires associés dans `src/`.

---

## 2. Décisions d'Architecture

### D1. Point d'Entrée Minimal & Test Natif
- **Décision :** Créer `src/index.js` avec en-tête JSDoc (KISS) et `src/index.test.js` avec le testeur natif `node --test`.
- **Raison :** Satisfaire les scripts `npm run build` (`esbuild`) et `npm test` de la CI.

---

## 3. Conséquences

### Positives :
- Pipeline CI 100 % verte sur GitHub Actions.
- Résolution des erreurs de build et de test sur Node.js 20.x et 22.x.
