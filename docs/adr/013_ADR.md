# 013_ADR: Adoption Officielle du Standard de Code StandardJS

- **Statut :** Accepté (Accepted)
- **Auteurs :** Thomas Gauthier & Antigravity (Google DeepMind Team)
- **Date :** 2026-07-28
- **Version du Plugin :** v1.0.0-alpha.1

---

## 1. Contexte & Problématique

Pour garantir la lisibilité, la cohérence stylistique et l'absence d'erreurs de syntaxe à travers l'ensemble de la codebase `herdr-voice` et des contributions des agents IA, une norme stricte et automatisée de linter/formatter est requise.

---

## 2. Décisions d'Architecture

### D1. Adoption de StandardJS
- **Décision :** Le projet `herdr-voice` adopte **StandardJS** (`standard`) comme linter et formatter officiel avec l'exclusion `"standard": { "ignore": ["dist/**", "tmp/**"] }`.
- **Raison :** Offrir un style JavaScript moderne, sans configuration lourde, sans point-virgule et avec une indentation de 2 espaces.

### D2. Inviolabilité du Script Precommit
- **Décision :** Le script `"precommit"` exécuté dans `package.json` est mis à jour vers `"npm run lint && npm test"`.
- **Raison :** Aucun commit ne peut être effectué si une erreur de linter ou un test unitaire échoue.

### D3. Directives Agents & Badges
- **Décision :** L'ADR-013 est inscrit dans `AGENTS.md` comme norme obligatoire de gouvernance pour les agents IA builders. Le badge officiel StandardJS est ajouté dans `README.md`.

---

## 3. Conséquences

### Positives :
- Cohérence stylistique irréprochable sur l'ensemble de la codebase.
- Détection et prévention automatique des erreurs avant chaque commit.
